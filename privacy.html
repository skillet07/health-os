Privacy policy

Last updated: 2026-10-24

Health OS is a personal application used by one person – its owner. It accesses only the owner's own Google Health data, with read-only scopes, after the owner grants consent.

Data accessed

Activity and fitness, health metrics and measurements, sleep, and basic profile data from the Google Health API.

How data is used

Data is stored on the owner's private server and used only to produce personal summaries and recommendations for the owner. Data is not sold, not shared with third parties for advertising, and not used for any purpose unrelated to the owner's own health tracking.

Retention and deletion

The owner can revoke access at any time at myaccount.google.com/permissions and delete stored data from the private server.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
